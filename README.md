# Walmart Sales Analysis - Power BI Dashboard

![Dashboard Preview](https://drive.google.com/uc?id=15NmR3dW2GXzZdJDg-14SaUTX7QClrnh5)

## 📌 Overview
This Power BI project provides a comprehensive sales analysis for Walmart, offering insights into sales performance, trends, and key business metrics. The dashboard is designed to help stakeholders make data-driven decisions using interactive visualizations.

## ✨ Features
✅ **Sales Performance Analysis:** Track total sales (£1.20M), average sales (£141), and trends over time.  
✅ **Product Insights:** Identify top-performing and underperforming product categories.  
✅ **Customer Insights:** Analyze customer buying patterns and preferences.  
✅ **Revenue & Profitability:** Evaluate revenue streams and profit margins.  
✅ **Outlet Analysis:** Assess sales contributions from different outlet sizes and locations.  
✅ **Key Performance Indicators (KPIs):** Measure business success using key metrics.  
✅ **Filtering Options:** Users can filter data by Outlet Location, Outlet Size, and Item Type for in-depth analysis.  

## 📊 Dashboard Components
- 📌 **KPI Cards:** Display total sales, average sales, number of items, and average rating.
- 📊 **Pie Charts:** Show distribution of fat content in products and outlet size segmentation.
- 📈 **Bar Charts:** Breakdown of sales by product categories and fat content by outlet.
- 📉 **Stacked Bars:** Represent outlet location-based sales performance.
- 📆 **Trend Analysis:** Track historical sales trends over time.
- 📑 **Tables with Metrics:** Provide a detailed comparison of sales, item counts, ratings, and visibility per outlet type.

## 📈 Insights and Findings
- **Sales Trends:** The peak sales period was observed in 2018 (£205K), followed by fluctuations.
- **Outlet Performance:** Tier 3 outlets contributed the highest sales (£472.13K), followed by Tier 2 (£393.15K) and Tier 1 (£336.40K).
- **Product Category Sales:** Fruits, Snack Foods, and Household items lead in total sales.
- **Fat Content Distribution:** Regular products have a significantly higher sales share than low-fat products.
- **Outlet Type Analysis:** Supermarket Type 1 had the highest sales (£787.55K), while Grocery Stores had the lowest (£151.94K).
